# 🚀 AI Resume Analyzer - Land Your Dream Job

> **Live Demo:** https://ai-resume-analyser-gzbhe7maspu6mgbkvfdacw.streamlit.app

An AI-powered tool to make your resume ATS-ready. Built with Streamlit and Google Gemini AI.

### ✨ Features

- **📊 Instant ATS Score:** Get your resume score out of 100 with detailed breakdown
- **🎯 Job Description Match:** Paste any JD and see how well your resume matches
- **💡 Smart Suggestions:** AI-powered recommendations to improve your resume
- **✉️ Cover Letter Generator:** Auto-generate a tailored cover letter for any job
- **🔒 Privacy First:** Your resume is never stored

### 🛠️ Tech Stack

- **Frontend:** Streamlit
- **AI Engine:** Google Gemini 1.5 Flash
- **PDF Processing:** PyPDF2
- **Deployment:** Streamlit Cloud

### ⚙️ How It Works

1.  Upload your resume (PDF)
2.  Get instant ATS analysis
3.  Paste a Job Description to check match percentage
4.  Generate a custom cover letter
